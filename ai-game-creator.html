Free AI Game Creator

Describe a simple 2D browser game in plain English and get a playable HTML5 version generated live. Inspect it, copy it, download it, or start over.

Up to 500 characters. Keep it simple: one mechanic, keyboard or mouse controls. Examples: “snake with arrows”, “click the falling apples”, “tiny maze escape”.

How it works

  1. Type a short description of the 2D game you want.
  2. Press Generate Game — your prompt is sent to the free Pollinations AI ↗ endpoint. No account, no API key, nothing to install.
  3. The returned HTML/CSS/JS is validated, stripped of unsafe markup, and run inside a sandboxed iframe that has no access to this website — only scripting inside its own isolated bubble is allowed.
  4. Use Copy Code or Download HTML to keep your game, and Reset Preview to try another idea.

Limitations

  • The free AI service is shared and rate-limited — generation can take up to ~90 seconds. If it fails, just try again.
  • Keep expectations modest: simple single-file 2D games only. Complex requests often produce rough results.
  • Generated code is provided as-is — test it before sharing.
